# E-SAR System

E-SAR เป็นระบบเว็บแอปพลิเคชันสำหรับจัดเก็บและบริหารข้อมูลตัวชี้วัด (KPI) ของหน่วยงาน โดยช่วยรวบรวมข้อมูลที่เกี่ยวข้องกับตัวชี้วัดให้อยู่ในระบบเดียว เช่น แผนกลยุทธ์ ค่าเป้าหมาย ผลการดำเนินงาน และหลักฐานประกอบ

ระบบสามารถกำหนดผู้รับผิดชอบตัวชี้วัด บันทึกผลการดำเนินงาน อัปโหลดหลักฐาน และติดตามสถานะของแต่ละตัวชี้วัดได้ รวมถึงมี Dashboard สำหรับดูภาพรวมของข้อมูล

## Technology

* Frontend: Angular
* Backend: Node.js, Express.js
* Database: MySQL
* API: REST API
* Authentication: JWT
* Version Control: Git & GitHub
